# س · SEEN — Spatial Virtual T-Shirt E-Commerce Store

A dark-luxury spatial virtual T-shirt try-on e-commerce storefront featuring **Men's (12)** and **Women's (12)** headless sculptural mannequin collections (24 studio T-shirts total), responsive across Desktop, Tablet, and Mobile.

## Highlights
- **Men & Women Dual Storefront:** Top `♂ Men | ♀ Women` switcher with separate 12-tee Men's and 12-tee Women's collections on pure dark-platinum matte headless sculptural mannequins.
- **Women-Only Live Color Palette:** Bottom-left favorite color palette widget (shown exclusively in the Women's section) with 10 curated shades that live-tint the female mannequin in real time.
- **All-24 Visual Lookbook & Wishlist (`♥`):** Searchable, filterable visual catalog modal with 1-click **Try On 3D**.
- **Active Transaction Gateway:** Custom sharp vector **bKash** icon with concealed merchant account verification (`TrxID`), plus Nagad, Rocket, SSLCommerz (Card), Cash on Delivery, promo codes (`SEEN10`, `JAYED10`), printable HTML invoices, and live Order Tracking.
- **Admin Control Center:** Auto-mockup studio for single/batch Men & Women T-shirt uploads with live `Scale`, `Y-Pos`, and `Folds` precision sliders, live Orders & Transactions ledger with CSV export, and JSON Store Snapshot backup/handover.
- **Zero-Dependency Full-Stack Local Server:** Double-click `start-store.bat` (or run `server.ps1`) for live persistent JSON API storage (`data/orders.json`, `data/catalog.json`, `data/config.json`) — or deploy statically straight to GitHub Pages / Netlify / Vercel.
